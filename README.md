# 🏨 Sistema de Gestión Hotelera - API REST

API REST para gestión hotelera desarrollada con Node.js, Express y MongoDB.

## 📋 Descripción
Sistema backend para la gestión de un hotel, incluyendo administración de clientes, habitaciones y reservas.

## 🚀 Tecnologías
- **Node.js** - Entorno de ejecución
- **Express.js** - Framework web
- **MongoDB** - Base de datos NoSQL
- **Mongoose** - ODM para MongoDB
- **Postman** - Pruebas de API
